# RegistroDePonto
## Programa para marcar horario de entrata e horario de saída.

### O marcador de ponto te da opções para criar um usuario ou selecionar um ja existe.

## Na opção 1 ele pede para digitar o nome do usuário e cria um arquivo excel com o nome do usuário. Apertando enter, ele marca o horário de entrada, em seguida, mesmo fechando o aplicativo, quando voltar e selecionar o usuário, apertando enter, ele marcara a saída. 1️⃣

## Na opção 2, ele abre a lista de usuarios existentes no diretório especificado, ao selecionar, o usuário poderá marcar sua saída ou entrada. 2️⃣

### O programa gera no arquivo xml, a data e hora exata em que o ponto foi registrado, gerando assim um controle melhor. ⌚
